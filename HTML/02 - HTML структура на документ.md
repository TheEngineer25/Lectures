


# 📘 HTML структура на документ

> [!abstract] Какво ще науча?
> - Ще разбера елементите, които се съдържат във всяка една уеб страница.
> - Ще мога да ги използвам на практика.

---

## 01 · Теория

Първото нещо, което трябва да научим за HTML, е неговата обща структура. Това е структура, която се съдържа във всеки един HTML документ.
Първото нещо, което обикновено имаме в една нова уеб страница, е т.нар. `DOCTYPE`.

---

## 02 · Примери с код

### HTML

```html
<!DOCTYPE html>
```

>[!important] Важно
>По този начин указваме на браузъра, че този документ ще използва HTML!

След това трябва да създадем `<html>` елемент.

### HTML

```html
<!DOCTYPE html>
<html></html>
```

За съдържание ние всъщност ще поставим друг елемент вътре в `<html>`.
За начало, ние ще започнем с елемента `<head>`.

### HTML

```html
<!DOCTYPE html>
<html>
<head></head>
</html>
```

Сега да добавим и елемента `<body>`.

### HTML

```html
<!DOCTYPE html>
<html>
<head></head>
<body></body>
</html>
```

`<head>` е за елементи, които не се виждат на страницата ни. Той съдържа заглавието на страницата, метаданни, връзка към CSS и др. неща. За момента ние ще попълним само заглавието на страницата с тага `<title>`.

### HTML

```html
<!DOCTYPE html>
<html>
<head>
	<title>The Basic Language of the Web: HTML</title>
</head>
<body></body>
</html>
```

`<body>` всъщност е за елементите, които ще се виждат на нашата страница. Нека да поставим едно заглавие и да видим това.

### HTML

```html
<!DOCTYPE html>
<html>
<head>
	<title>The Basic Language of the Web: HTML</title>
</head>
<body>
	<h1>The Basic Language of the Web: HTML</h1>
</body>
</html>
```

Нека сега да видим как изглежда това в браузъра.
